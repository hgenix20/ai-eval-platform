# AI Eval Platform

Evaluation and reliability platform for AI systems: a curated catalog of the
benchmarks that still discriminate in 2026, built suites for what no public
benchmark measures, and a regression gate that blocks a pull request on
accuracy, safety, cost, or latency.

Status: Phase 1 in progress. Design: docs/superpowers/specs/2026-09-07-ai-eval-platform-design.md
